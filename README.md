# SBU Hacks

This repository contains three independent hackathon projects:

- [Train Discovery](Train-Discovery/): LIRR ride companion (Next.js PWA)
- [Human Engine](Human-Engine/)
- [SteamScholar](SteamScholar/)

To run Train Discovery locally:

```bash
cd Train-Discovery
npm ci
npm run dev
```

See [Train Discovery's README](Train-Discovery/README.md) for setup, API keys, and verification instructions.
